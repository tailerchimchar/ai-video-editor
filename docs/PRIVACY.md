# Privacy policy: AVE PC uploader

The "AVE PC uploader" Google OAuth client belongs to the ai-video-editor
project and is used only by its developer.

- It runs on the developer's own computer and uploads video clips and JSON
  summaries into a Google Drive account the developer controls.
- It requests only the `drive.file` scope: it can see and manage files it
  created itself, nothing else in the Drive.
- No data is collected from anyone else, shared with third parties, sold,
  or used for advertising.
- Credentials stay on the developer's computer in a local configuration file.

Contact: open an issue on this repository.
