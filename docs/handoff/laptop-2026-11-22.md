## What the laptop needs

1. **Tools**: Git, Python 3.10+, `uv` (`winget install astral-sh.uv`), ffmpeg + ffprobe on PATH (`winget install Gyan.FFmpeg`), 7-Zip or built-in zip extraction, and a GitHub login that can read the repo.
2. **Repo**: `git clone https://github.com/tailerchimchar/ai-video-editor && cd ai-video-editor/api && uv sync`.
3. **Secrets**: copy `api/.env` from the PC by hand (USB stick or password manager). Needed keys: `ANTHROPIC_API_KEY`, `RIOT_API_KEY`, `RIOT_ID`, `MIC_STREAM_OVERRIDE=2`, `SHORTS_BEAT_SYNC_ENABLED=true`, the `GROKBOT_DRIVE_*` values if the laptop should upload to Drive. Then set laptop paths: `OUTPLAYED_MEDIA_DIR`, `WORKSPACE_DIR`, `DATABASE_PATH` (absolute). Claude never reads this file; the owner edits it.
4. **Footage**: download `handoff/jhin/jhin_2026-11-20_raw.mp4` (3.2 GB) from Drive into `<OUTPLAYED_MEDIA_DIR>\League of Legends\League of Legends_11-20-2026_20-1-10-276\League of Legends_11-20-2026_20-35-21-0.mp4` (keep that folder and file name: the cached data refers to it).
5. **Cached data**: download `handoff/jhin/jhin_handoff_bundle_2026-11-22.zip` and unzip its `ws/` folder into `WORKSPACE_DIR` (it contains `riot/<asset>/` match, timeline, meta, lane; `plays/<asset>.json`; `mic/<asset>.json`; the panel round folder without its transcript; `story/story_v3.json`). 6. **Database row**: the pipeline keys everything by asset id `42672a10-5b17-4f60-9231-933b3c90ab97`. Insert the row from `asset_row.json` into the laptop's `assets` table with `path` rewritten to the laptop's footage path (columns: id, filename, path, game, created_at, indexed_at, source_origin, source_deleted_at, parent_asset_id, duration_seconds).
