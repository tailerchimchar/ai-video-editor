# Wave crash
Push the wave into the enemy tower so the minions hit it. You do this right
before a recall, so you lose as little as possible while you're away.

> Owner: "show that i crash the wave and recall"

**On screen:** minions reaching the enemy tower, then the owner backs off and recalls.
